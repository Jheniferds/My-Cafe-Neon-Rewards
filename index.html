Privacidade dos registros

Cada conta enxerga apenas as próprias distribuições. No Supabase isso é garantido por RLS (execute o arquivo supabase-setup.sql); no modo local, o histórico fica separado por e-mail neste navegador.

Supabase

O modo local serve para testar. Para manter o histórico entre dispositivos, configure a URL e a chave pública (anon/publishable) do seu projeto no início do arquivo HTML e execute o SQL fornecido com este projeto. Nunca coloque a service_role key no navegador.
